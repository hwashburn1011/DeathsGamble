# `characters/`

Per-build character sprite sheets (idle / walk / attack / hurt / death).

Currently empty — character sprites for the 8 builds (Gambler, Duelist,
Brute, Arcanist, Rogue, Huntsman, Witch, Soldier) will land in Phase C
when we replace `src/engine/charSprites.ts` (canvas-drawn placeholders)
with real animated PixiJS sprites.

Source candidates:
- `tiles/kenney-tiny-dungeon/tiles/` — has many small character tiles already
  bundled with the Tiny Dungeon pack (CC0)
- LPC Medieval Fantasy Character Sprites (OpenGameArt, CC-BY-SA)
- itch.io free roguelite character packs

See `../SOURCES.md` for full list.
